DevTools Hub 소개

프레임워크와 빌드 스텝 없이 순수 Vanilla JavaScript와 브라우저 네이티브 API(Web Crypto, Intl, Canvas)로 만들어졌고, 오픈소스(MIT)로 GitHub에 공개되어 있습니다. JWT 토큰·비밀번호·파일 같은 민감한 입력도 네트워크로 전송되지 않아 안심하고 사용할 수 있습니다.

Built with pure vanilla JavaScript and native browser APIs (Web Crypto, Intl, Canvas) — no framework, no build step. Open source (MIT) on GitHub. Sensitive inputs like JWT tokens, passwords and files never leave your browser.
